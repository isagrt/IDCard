# Cartão de Visita Digital — Isadora Goedert

## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de **Design de Serviço**, com o objetivo de fortalecer o marketing pessoal e facilitar o acesso às minhas informações profissionais por meio de um cartão de visita digital interativo.

A proposta é apresentar minha identidade visual de forma criativa e acessível, reunindo meus principais canais de contato em um único lugar. O cartão foi desenvolvido para transmitir minha personalidade e minha área de atuação em Design Gráfico e Digital.

## Funcionalidades

- Cartão digital com frente e verso.
- Animação interativa para girar o cartão.
- Links clicáveis para telefone, e-mail, LinkedIn e portfólio.
- Informações de localização.
- Botão para iniciar o envio de um e-mail.
- Layout responsivo, adaptado para diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo do cartão.
- **CSS3:** estilização, responsividade e animação 3D.
- **JavaScript:** interatividade e controle do giro do cartão.
- **GitHub Pages:** hospedagem gratuita do projeto.

## Publicação

O cartão está hospedado no GitHub Pages e pode ser acessado por meio de seu endereço público. Esse endereço também pode ser utilizado para gerar um QR Code, facilitando o compartilhamento do cartão.
