# Cartão digital interativo — Isadora Goedert

Cartão de visita responsivo com frente ilustrada, verso interativo e efeito 3D de virar.

## Arquivos
- `index.html`: conteúdo e links.
- `style.css`: layout, paleta e animação 3D.
- `script.js`: interação para virar o cartão e configuração do link de portfólio.
- `assets/frente-cartao.png`: capa fornecida.

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e a pasta `assets`.
3. Abra Settings → Pages.
4. Escolha publicar a partir da branch `main`, pasta `/ (root)`.
5. Use o endereço gerado pelo GitHub Pages para criar o QR Code.
6. Para manter o QR Code, não altere o endereço nem o nome do repositório. Faça atualizações no mesmo repositório.

## Observações
- Os links de contato ficam públicos, como em qualquer cartão digital.
- A capa usa a arte enviada pelo usuário. Para trocar, substitua `assets/frente-cartao.png`, mantendo o nome do arquivo.
- O verso é HTML real: os links e o botão de e-mail são clicáveis.
